## The app's rules [C]
1. Scan screen list (all nearby BLE devices): a device with no name is ignored; a name containing BLE (any case) is hidden; otherwise it is shown when the name contains the stored signal name (case-insensitive raw substring; the signal name comes from the server product record) or the name matcher is true.
2. Name matcher: trim, upper-case, delete every character that is not A to Z or 0 to 9, then test whether the result contains NEO or BDEVICE (from "B-Device"). These two strings are the only hard-coded names.
3. After a tap the same matcher decides the path: match goes to the BadgeSdk path, anything else goes to nn20. The "is connected" check uses the same matcher.
4. The BadgeSdk has its own scanner that ignores names: it parses the manufacturer AD record (at least 10 bytes) and accepts only device type BAJI (tag 0xB3), reading shape (0x6C square, 0x6D circle).
5. The pets screen uses a stricter, separate rule (case-sensitive signal name, no BLE hiding); it is a different product.

## Differences to the client
| Item | App | Client | Verdict |
|---|---|---|---|
| Unnamed devices | ignored on the scan list | accepted when the AD tag is 0xB3 | broader on purpose (the SDK scanner also does this) |
| Name normalising for the signal name | raw upper-case substring | normalised, punctuation ignored | broader, harmless |
| BLE in the name | always hidden | hidden by default, but a name passed with `--name` or `--model` is accepted first | broader on purpose (problem log 32: `Nikko-badge(BLE)`) |
| Default names | NEO, B-Device and the server signal name | NEO, B-Device, E-badge plus model names | broader on purpose (E-badge is the pairing-screen name of Nano and Niji [W]) |
| Watch tag | 0xB9 | was 0xB5 | client bug, fixed (problem 75), test `test_device_tags_match_the_sdk_enum` |
| Other tags and shapes | 0xB0, 0xB1, 0xB2, 0xB3; 0x6C, 0x6D | same | equal |
| Path choice | by name matcher | by service discovery (`detect_transport`) | different on purpose: services are better evidence than a name; the name rule is documented for comparison |

Nothing in the client misses a device the app would show. A name such as a Nikko with BLE in it is visible only with `--name`/`--model`, as documented.
