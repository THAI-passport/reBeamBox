# Synthetic capture fixtures

SYNTHETIC. Generated by `tools/make_fixtures.py` from this repository's own frame builders and a fixed test JPEG. They contain no vendor data and are not recordings of any badge or of the vendor app. Each scenario exists as btsnoop (HCI H4, datalink 1002) and pcapng (linktype 201).

- `nn20_animation_ack`: discovery, status push, settings frame, a 3-frame 368x368 animation container in 88-byte packets (MTU 100) with fragmented ACL packets and GetPacketSuccess replies in batches of 4.
- `rcsp_auth_session`: complete Jieli auth (reset, 00|R, 01|E1(R), 02 pass, 00|Rdev, 01|E1(Rdev), 02 pass) and a GetTargetInfo command.
- `malformed`: an nn20 transfer with a bad checksum (packet 2) and a dropped packet (5), plus RCSP file chunks with a bad CRC16 (chunk 1) and a dropped sequence number (chunk 3).

Regenerate with `python tools/make_fixtures.py`; `--check` verifies the committed files.
